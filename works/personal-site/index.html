Overview

HTML, CSS, JavaScript만으로 만든 정적 사이트. GitHub에 올리면 Netlify가 배포하고, 항목은 JSON 파일 한 곳에서 관리.

Intent

수업마다 흩어진 결과물을 한곳에서 볼 수 있게 하는 것이 목표. 파일 이름이 아니라 내용으로 항목을 찾도록 구성.

Direction

항목 이름
문서 종류가 아니라 담은 내용으로 짓기
공개 범위
영상, 원본 데이터, 교수님 제공 자료는 올리지 않기
배포 환경
Netlify 무료 플랜에 맞춰 빌드 없는 정적 파일과 WebP 이미지 사용

Process

  1. 01작업 지시서 작성: 범위와 디자인 기준 확정
  2. 02해외 수상작 포트폴리오의 홈 화면 구성과 동작을 분석해 프로젝트 선택기로 설계
  3. 03프로젝트 파일 점검: 교수님 제공 자료, 원본 데이터, 영상 제외
  4. 04이미지를 WebP로 변환
  5. 05항목 데이터를 JSON 한 곳에 모으고, 페이지를 만드는 스크립트 작성
