Overview

HTML, CSS, JavaScript만으로 만든 정적 사이트. GitHub 저장소와 Netlify를 연결해 배포하며, 항목 데이터는 JSON 파일 한 곳에서 관리함.

Process

  1. 작업 지시서를 작성해 범위와 디자인 기준을 정함
  2. 프로젝트 파일을 점검하고 교수님 제공 자료, 원본 데이터, 영상을 제외
  3. 이미지는 WebP로 변환해 사이트 자산으로 준비
  4. data/works.json 한 건을 더하면 항목이 추가되도록 페이지 생성 스크립트 작성
  5. GitHub에 올리면 Netlify가 자동 배포
