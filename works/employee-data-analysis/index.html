분석 코드 생성 프롬프트Claude

초기 요청을 Claude와 협의해 분석 5개와 출력 형식을 구체화한 최종본

다음의 상황을 읽고 적절한 코드를 생성해줘

데이터 파일 : 'unified_statistics_data.csv', 데이터 파일은 폴더에 업로드 되었고 데이터 파일 중 10개의 행을 첨부하였음.
10개 행 첨부한 파일 : '샘플 데이터 추출 파일' (열어서 확인할 것)
언어 : python 언어를 사용
데이터 설명 파일 : 'data_description'

태스크 : 아래 5개 분석을 모두 수행하는 하나의 python 코드를 작성

[0. 공통 전처리 및 기술통계]
- 변수: 모든 연속형 변수 (Age, IQ, Experience, Salary, Performance, Pre_Score, Post_Score, Satisf_1~3, Social_Score, Tech_Score, Extra_Feature)
- Age, Salary 결측치는 중앙값으로 대체 (결측 개수와 대체 방식을 기록)
- 평균, 표준편차, 최소/최대, 왜도, 결측 수, IQR 기준 이상치 수를 표로 정리
- Performance의 100점 천장 효과 비율도 확인

[1. 대응표본 t-test (+ Wilcoxon 부호순위 검정 병행)]
- 변수: Pre_Score, Post_Score
- 알 수 있는 것: 교육 후 점수가 유의하게 향상되었는지(교육 효과). 평균 차이, 95% 신뢰구간, t, p, Cohen's d, 차이의 정규성 검정(Shapiro-Wilk) 포함

[2. 일원 ANOVA + 사후검정(Tukey HSD), 독립표본 t-test]
- 변수: Salary를 Education, Region별로 ANOVA / Gender별로 독립표본 t-test (Performance도 Gender별 비교)
- 알 수 있는 것: 학력, 지역, 성별에 따른 연봉 차이 유무와 차이가 나는 집단. 정규성, 등분산(Levene) 검정을 함께 보고하고, 가정 위반 시 Kruskal-Wallis/Welch 결과도 병기. 효과크기(eta-squared 또는 Cohen's d) 포함

[3. 다중회귀분석 (OLS)]
- 변수: 종속변수 Salary, 독립변수 Experience, IQ, Age
- 알 수 있는 것: 연봉에 영향을 주는 요인과 영향 크기. 계수, 표준오차, t, p, 95% 신뢰구간, R², 조정 R², F검정, VIF(다중공선성), 잔차 정규성/등분산 검정, 표준화 계수 포함

[4. 이진 분류 (로지스틱 회귀, 랜덤포레스트, 그래디언트부스팅)]
- 종속변수: Promotion
- 독립변수: Age, IQ, Experience, Salary, Performance, Pre_Score, Post_Score, 교육 향상도(Post_Score − Pre_Score), 만족도 평균(Satisf_1~3 평균), Social_Score, Tech_Score, Extra_Feature, 범주형 3개(Gender, Region, Education은 원-핫 인코딩)
- 층화 train/test 분할(8:2) 및 5-겹 층화 교차검증, random_state=42, 로지스틱은 표준화 적용
- 알 수 있는 것: 승진 여부를 예측하는 성능(Accuracy, Precision, Recall, F1, ROC-AUC, 혼동행렬)과 승진에 영향을 주는 핵심 요인 (로지스틱 계수/오즈비, 랜덤포레스트·그래디언트부스팅 변수 중요도, 가능하면 permutation importance). 클래스 불균형 여부도 확인하고 모델 3종의 성능을 비교표로 정리

[5. K-Means 군집분석]
- 변수: Social_Score, Tech_Score, Extra_Feature (표준화 후 사용)
- k=2~6 범위에서 엘보우(inertia)와 실루엣 점수로 최적 군집 수 결정
- 알 수 있는 것: 숨은 집단 구조. 군집별 변수 평균 프로파일, 군집 크기, 실제 Group_Label과의 일치도(ARI, 교차표) 포함

출력내용 : 주요 분석에 활용할 결과물을 출력하되, 'result.txt'에 분석 방법과 주요 결과에 대한 표, 수치와 간단한 해석을 추가

* result.txt는 이후 보고서 생성에 사용하므로 반드시 파일로 저장할 것
* result.txt 요구사항:
- UTF-8로 저장하고, 콘솔 출력과 동일한 내용이 파일에도 저장되게 할 것
- 분석 0~5 순서로 구성하고, 각 분석마다 [분석 목적 / 사용 변수 / 분석 방법 / 결과표(텍스트 표) / 핵심 수치 / 간단한 해석] 항목을 포함할 것
- 전처리 내역(결측 처리, 표본 수, 이상치), 사용한 검정의 가정 확인 결과, 유의수준(α=0.05)을 처음에 명시할 것
- 모든 수치는 코드 실행 결과로만 쓰고, 해석 문장은 그 수치에 근거할 것
* 그래프(히스토그램, 상관 히트맵, 박스플롯, ROC 곡선, 변수 중요도, 엘보우/실루엣 등)는 png 파일로 별도 폴더(figures)에 저장하고, 파일명을 result.txt에 기록할 것
* 코드는 하나의 .py 파일로, 실행하면 result.txt와 figures가 한 번에 생성되도록 하고, 필요한 라이브러리(pandas, scipy, statsmodels, scikit-learn, matplotlib, seaborn) 설치 안내도 포함할 것
보고서 생성 프롬프트Claude

분석 결과 파일과 그래프 11개를 첨부해 5쪽 분량의 사내 보고서 작성

이제부터 너는 기업의 데이터를 분석하고 제안하는 전문가야.
첨부한 'result.txt'는 데이터를 분석한 주요 결과를 출력한 파일이야. 분석은 파이썬 언어로 작성했고, 분석 코드는 'run_unified_analysis.py'야.
데이터는 10개 행을 함께 첨부했어. 'data_description.txt'라는 파일에는 열에 대한 설명이 저장되어 있어.

[분석 개요]
분석 데이터는 'unified_statistics_data.csv'(직원 10,000명, 변수 19개)야.
분석은 아래 5가지 방법으로 수행했어.
0. 전처리 및 기술통계: Age, Salary 결측치를 중앙값으로 대체하고 변수별 분포, 이상치, Performance 천장 효과를 점검
1. 대응표본 t-test(+ Wilcoxon 검정): Pre_Score와 Post_Score를 비교하여 교육 효과를 검증
2. 일원 ANOVA(+ Tukey 사후검정), 독립표본 t-test: 학력·지역·성별에 따라 연봉과 업무 성과에 차이가 있는지 검증
3. 다중회귀분석: Target은 Salary이고, Feature는 Experience, IQ, Age야. 경력·IQ·나이가 연봉과 각각 어떤 관계인지 분석하여 연봉 결정요인을 파악하고 예측
4. 이진 분류(로지스틱 회귀, 랜덤포레스트, 그래디언트부스팅): Target은 Promotion(승진 여부)이고, Feature는 Age, IQ, Experience, Salary, Performance, Pre_Score, Post_Score, 교육 향상도(Post_Score − Pre_Score), 만족도 평균(Satisf_1~3 평균), Social_Score, Tech_Score, Extra_Feature, Gender, Region, Education이야. 모델 성능(AUC, F1)과 승진에 영향을 주는 핵심 요인을 분석
5. K-Means 군집분석: Social_Score, Tech_Score, Extra_Feature로 숨은 집단을 찾고 실제 Group_Label과 비교

'result.txt'와 첨부한 그래프 11개(figures 폴더)를 이용하여 분석 보고서를 작성하려고 해.

[작성 요청]
기업의 비즈니스 보고용으로 자세한 결과 분석 보고서를 생성해줘.
- 보고서의 본문 길이는 A4 5장으로 생성해줘. 필요하면 표를 넣어줘.
- 기업 내부 보고용 문서이므로 과목·학번·이름 같은 항목 없이, 표지(제목·부제), 목차, 핵심 요약, 본문, 출처 및 참고 순서로 구성해줘.
- 첨부한 그래프는 해당 분석 절에 삽입할 위치를 '[그림 n]'으로 표시하고, 그림마다 제목과 한 줄 해석을 달아줘. 그 외에 그림이 더 필요하면 그림을 그릴 수 있는 프롬프트를 해당 위치에 포함시켜줘.
- "~이다", "~한다"와 같은 평서문으로 작성해줘.
- 기계학습에 대해 잘 모르는 사람이 이해할 수 있는 쉬운 용어와 표현을 사용해줘. 전문 용어(p-value, AUC, ARI 등)는 처음 나올 때 한 줄로 풀어서 설명해줘.
- 비즈니스에 활용할 수 있는 Insight와 함의도 자세하게 제안해줘. (예: 교육 프로그램 운영, 연봉 체계, 승진 기준, 인재 유형별 관리)
- Markdown 문서 형식은 제외해줘. (#, **, 마크다운 표 문법 등을 쓰지 말고, 일반 보고서 형식의 제목·번호 목록·표로 작성)

[작성 규칙]
- 수치는 반드시 'result.txt'에 있는 값만 인용하고, 없는 수치는 만들지 마.
- 'result.txt'의 해석 문장과 결과표 수치가 다르면 결과표 수치를 따라줘.
- 변수 설명은 'data_description.txt'를 따라줘.
- 상관관계를 인과관계처럼 쓰지 마.
- 마지막에 '분석 시 유의점'을 3~4줄로 짧게 정리해줘. 데이터의 문제점이 아니라 결과를 해석할 때 참고할 사항(예: Performance가 만점에 몰려 있는 특성, 상관관계는 인과관계가 아니라는 점, 예측 모델의 한계)으로 써줘.

[권장 구성]
1. 분석 개요(목적, 데이터, 방법) 2. 데이터 현황 3. 교육 효과 4. 집단 간 차이 5. 연봉 결정요인 6. 승진 예측 7. 인재 유형 군집 8. 종합 Insight 및 제안 9. 분석 시 유의점

Claude가 쓴 보고서를 다른 AI가 분석 결과 원본과 대조

너는 기업 보고서를 검토하는 데이터 분석 전문 검토자야.
첨부한 '분석_보고서.docx'는 다른 AI가 작성한 직원 데이터 분석 보고서야. 'result.txt'는 분석 결과 원본, 'run_unified_analysis.py'는 분석 코드, 'data_description.txt'는 변수 설명이야.
보고서를 result.txt와 코드에 맞춰 교차검증하고, 수정이 필요한 부분을 찾아줘. 보고서 전체를 새로 쓰지는 말고, 문제가 있는 곳만 지적해줘.

[검토 항목]
1. 수치 정확성: 보고서의 모든 수치(평균, p-value, 효과크기, R², 회귀계수, 모델 성능, 군집 결과 등)를 result.txt와 하나씩 대조해줘. 불일치하거나 result.txt에 없는 수치는 반드시 표시해줘.
2. 통계 해석의 타당성: 검정 선택이 적절한지, 유의성과 효과 크기를 올바르게 해석했는지, 상관관계를 인과관계처럼 쓰지 않았는지 확인해줘. 과장하거나 단정한 표현은 완화안을 제시해줘.
3. 변수 설명: data_description.txt와 다르게 설명한 곳이 있는지 확인해줘.
4. 논리와 Insight: 종합 Insight와 제안이 분석 결과에서 실제로 도출되는 내용인지, 근거 없는 제안이 없는지 확인해줘.
5. 문장과 표현: "~이다/~한다" 평서문이 일관되는지, 기계학습을 모르는 독자가 이해하기 어려운 용어나 설명 없는 약어가 있는지 확인해줘.
6. 형식: 표·그림 번호와 본문 참조가 일치하는지, 목차와 실제 절 제목이 맞는지, 용어 표기(예: Performance, AUC)가 일관되는지 확인해줘.

[출력 형식]
먼저 전체 평가를 3줄 이내로 쓰고, 그 아래에 아래 표로 정리해줘.
번호 | 위치(절·표·문장) | 검토 항목 | 문제 내용 | 수정 제안 | 중요도(상/중/하)
문제가 없는 항목은 "이상 없음"으로 표시하고, 검증한 수치의 개수도 알려줘.
확실하지 않은 것은 추측하지 말고 "확인 필요"라고 써줘.
