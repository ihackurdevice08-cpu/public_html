직원 10,000명 데이터에 던진 네 가지 질문

유형
데이터 분석
도구
Python, Claude, ChatGPT

교육 효과, 연봉, 승진, 인재 유형을 분석하고 다른 AI로 교차 검증한 보고서

Overview

변수 19개의 직원 데이터를 통계 분석 3종과 기계학습 2종으로 분석하고, 다른 생성형 AI로 교차 검증.

Process

  1. 01분석 범위 설정과 프롬프트 구체화
  2. 02Claude로 분석 코드와 보고서 1차본 작성
  3. 03보고서를 ChatGPT에 입력해 분석 결과 원본과 대조
  4. 04지적 사항을 검토해 보고서에 반영하고 수정 내역 기록
