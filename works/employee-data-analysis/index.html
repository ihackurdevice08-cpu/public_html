직원 데이터 통합 분석 보고서

Type
데이터 분석
Tools
Python, Claude, ChatGPT

직원 10,000명 데이터로 교육 효과, 연봉 결정요인, 승진 예측, 인재 유형을 분석한 보고서

Overview

변수 19개로 구성된 직원 데이터를 통계 분석 3종과 기계학습 2종으로 분석하고, 다른 생성형 AI로 교차 검증한 보고서.

Process

  1. 분석 범위 설정 후 프롬프트를 구체화하는 과정을 기록
  2. Claude로 분석 코드와 보고서 1차본 작성
  3. 작성한 보고서를 ChatGPT에 입력해 분석 결과 원본과 대조
  4. 지적된 사항을 검토해 보고서에 반영하고 수정 내역을 기록
