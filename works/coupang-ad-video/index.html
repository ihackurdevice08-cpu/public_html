쿠팡 광고영상 제작 과정

Type
영상 과제

광고영상 기획과 인물 모델링 과정을 기록한 과제

Overview

쿠팡 기업 조사에서 사업 부문이 폭넓게 확장된 것을 확인하고 이를 바탕으로 광고영상을 기획함. 영상은 올리지 않고 기획과 제작 과정만 정리함.

Process

  1. 기업 조사 1차 보고서 작성
  2. 제작 도구 선정과 인물 모델링: 같은 인물을 8개 시점으로 생성
  3. 스토리보드 작성
  4. 컷별 이미지 및 영상 생성 프롬프트 작성

Result
