가상 증권사 Hallym Investment의 보고서, 발표자료, 이미지, 영상으로 구성한 중간 과제

Overview

삼성전자와 SK하이닉스를 다룬 투자 보고서를 쓰고, 이를 바탕으로 발표자료와 이미지, 홍보 영상을 만든 과제. 투자 의견과 목표주가는 수업용 가상 설정임.

Process

  1. 자료조사는 GPT: 의견 없이 사실, 수치, 출처만 조사하도록 제한
  2. 조사를 2단계로 분리: 먼저 보고서 양식, 다음으로 내용(거시, 기업, 업황, 수급 순)
  3. 낙관 자료와 신중 자료를 같은 비중으로 수집
  4. 보고서 작성과 수정은 Claude: 13쪽 DOCX, 참고문헌 26건
  5. 발표자료 15장은 Claude skill로 생성
  6. 보고서 첫 화면 이미지를 만들고, 이를 활용해 영상 입력 이미지 7장을 생성
  7. Google Flow로 4초 클립 4개를 만들고 Claude로 자막, 로고, 소리를 합성해 약 20초 영상 제작
