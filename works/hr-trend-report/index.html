인사관리 최근 동향 및 실무 적용 방안

인구구조·기술·제도의 동시 변화에 대한 원리적 분석과 조직 대응 과제

인구구조, 기술, 제도 변화를 근거 자료로 확인하고 조직이 풀어야 할 과제까지 정리하는 것이 목표.

5쪽 분량 PDF 보고서를 만든 첫 요청

[역할] 나는 인사관리를 담당하는 부서의 직원이야.

[요청] 인사관리 방법의 최근 동향에 대한 보고서를 5페이지 분량으로 작성해 줘. 실무에서 사용하는 보고서 형식으로 만들 것.

[작성 조건]
- 각 항목에서 전달하려는 내용(what to say)이 분명하게 드러나게 작성
- 실제 동향을 기반으로 하고, 출처를 명확히 밝힐 것

[출력] pdf 파일
보고서 작성 프롬프트 (규격화)Claude

처음부터 쓰면 빠지는 항목이 생겨 역할·분량·어조·참고문헌·환각 방지 조건을 틀로 만들어 둔 것

[역할] 너는 기업 인사관리 부문의 전문가야. 나는 인사관리 담당 부서의 직원이고, 최근 인사관리 방법의 동향에 대한 보고서를 제작하려고 해.

[분량] A4 기준 30페이지로 제작해 줘. 실제 페이지 수도 30페이지가 나와야 해.

[어조] 보고서이므로 평서문을 사용하고, 전달하려는 내용이 명확히 드러나게 작성해 줘. 같은 맥락의 내용을 의미 없이 반복하지 마.

[내용 범위] 공개된 자료를 그대로 가져와 쓰지 말고, 원리를 먼저 학습한 뒤 실제 적용 방법까지 다뤄 줘. 동향을 다루는 보고서이므로 왜 이런 동향으로 가고 있는지, 이것이 미칠 영향과 보완점(모든 방식에는 장단점이 있음)도 함께 다뤄 줘.

[참고문헌과 환각 방지]
- 실제 공개된 최신 자료를 기반으로 작성하고, 본문에서 참고한 출처를 반드시 명시해 줘.
- 참고문헌은 장마다 쓰지 말고 보고서 마지막에 모아서 정리해 줘.
- 출처가 실제로 존재하는 참고문헌만 적어 줘.

[작업 순서]
1. 기획부터 시작해 보고서 작성 단계마다 md 파일로 기록을 남기면서 제작해 줘. 한 번에 결과물을 만들 때 생기는 품질 저하를 막고 일관성을 높이기 위한 방식이야.
2. 목차 생성을 가장 먼저 진행해 줘. 목차, 목차별 페이지 분량, 목차별 내용 요약을 먼저 정하고 md 파일로 저장해 줘. 목차 선정을 위한 자료 조사는 필요하지만, 내용 조사를 끝낸 뒤 목차를 억지로 끼워 맞추지는 마. 목차는 위에서 정한 전체 분량에 맞춰 작성해 줘.

[서식 사전 안내] 작업에 들어가기 전에 사용할 폰트 종류와 본문 폰트 크기(표 안의 텍스트는 왼쪽 맞춤 등)를 먼저 알려 줘. 분량을 맞추는 과정에서 폰트와 정렬을 반복해 바꾸거나 추가 조사를 되풀이하는 시간을 줄이기 위해서야.

[출력] Word 파일과 PDF 파일을 각각 제작해 줘. 두 파일은 확장자만 다르고 내용은 정확히 같아야 해.

작업 과정

  1. 근거 자료: 정부 통계, 법령 원문, 사용자단체 실태조사, 글로벌 HR 리서치
  2. 인용 자료는 본문에 번호로 표기하고 말미에 정리
  3. 조사 기반 수치는 응답자와 분모를 함께 기재
  4. 표지, 목차, 참고문헌 포함 30쪽
