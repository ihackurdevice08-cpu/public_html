승진 예측 및 연봉 결정요인 분석

Type
데이터 분석
Tools
Python, scikit-learn, Antigravity

직원 데이터 10,000건으로 승진 예측 모형과 연봉 회귀분석을 수행하고 보고서 4종으로 정리

Overview

Python으로 분석 도구를 만들어 엑셀 데이터를 분석함. LLM에 데이터를 직접 올리지 않고 코드를 생성해 분석하는 방식으로 진행함.

Process

  • 분석 코드 작성: 승진 예측용과 연봉 회귀용 Python 스크립트
  • 승진 예측: 로지스틱 회귀, 랜덤 포레스트, 그래디언트 부스팅 3종 비교, 학습 8,000건과 검증 2,000건
  • 연봉 결정요인: 결측치를 제외한 9,500건으로 OLS 다중회귀, 경력 1년당 연봉 약 180.6만 원 상승, 설명력 95.4%
  • 보고서 작성: 승진 예측 3쪽 요약본과 5쪽 상세본, 연봉 결정요인 2쪽 요약본과 4쪽 상세본
