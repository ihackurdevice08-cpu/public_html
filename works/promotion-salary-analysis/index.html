승진 예측 모형 3종 비교와 연봉 회귀분석, 보고서 4종

Overview

엑셀 데이터를 분석하는 Python 코드를 생성해 분석. LLM에 데이터를 직접 올리지 않음.

Process

  1. 분석 코드 작성: 승진 예측용, 연봉 회귀용 Python 스크립트
  2. 승진 예측: 로지스틱 회귀, 랜덤 포레스트, 그래디언트 부스팅 3종 비교 (학습 8,000건, 검증 2,000건)
  3. 연봉 결정요인: 결측치를 뺀 9,500건으로 OLS 다중회귀. 경력 1년당 연봉 약 180.6만 원 상승, 설명력 95.4%
  4. 보고서: 승진 예측 3쪽 요약본과 5쪽 상세본, 연봉 결정요인 2쪽 요약본과 4쪽 상세본

Result

다음 항목직원 10,000명 데이터에 던진 네 가지 질문

임상우, 20223029, 한림대학교
