Overview

유통기한이 2~10일인 신선식품은 폐기 손실과 품절 손실이 함께 발생. 예측값에 일괄 12% 버퍼를 더하는 기존 발주 규칙의 한계를 진단.

Intent

폐기와 품절을 함께 줄이는 발주량을 찾는 것이 목표. 예측값에 일괄 12%를 더하는 기존 규칙이 품목 특성을 반영하지 못하는 문제에서 출발.

Direction

진단 먼저
모델보다 기존 방식의 문제 확인이 먼저
품목별 기준
품목마다 다른 폐기와 품절 손실을 반영
검증
정책 효과를 시뮬레이션 수치로 비교

Process

  1. 01데이터: 10,860행 31개 열, 풀필먼트 센터 2곳, SKU 30개, 181일, 카테고리 6개
  2. 02기존 예측의 구조적 오차와 편향 진단
  3. 03HistGradientBoosting 수요예측 모델 구축
  4. 04품목별 Newsvendor 임계비율을 반영한 발주 최적화와 시뮬레이션
