로켓프레시 신선식품 발주 최적화

Type
데이터 분석
Tools
Python, pandas, statsmodels, scikit-learn

신선식품의 폐기와 품절 사이의 균형을 Newsvendor 방식으로 분석한 보고

Overview

유통기한이 2~10일로 짧은 신선식품에서 폐기 손실과 품절 손실이 함께 생기는 문제를 다룸. 기존 예측값에 일괄 12% 안전 버퍼를 더하는 발주 규칙의 한계를 진단함.

Process

  1. 데이터: 10,860행 31개 열, 풀필먼트 센터 2곳, SKU 30개, 181일, 카테고리 6개
  2. 기존 예측의 구조적 오차와 편향 진단
  3. 머신러닝(HistGradientBoosting) 기반 수요예측 모델 구축
  4. 품목별 Newsvendor 임계비율을 반영한 발주 최적화와 시뮬레이션
