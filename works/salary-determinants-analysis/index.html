보고서 생성 프롬프트Claude

임원 보고용 개조식 보고서를 docx와 pdf로 작성

[역할] 너는 비즈니스 데이터를 분석하는 전문가야.

[배경] 'result.txt'는 데이터를 분석한 주요 결과를 출력한 파일이야. 분석은 다중회귀분석(Salary ← Experience, IQ, Age)로 수행했고, Python으로 작성했어. 데이터 설명은 첨부한 'data_description.txt'를 참고해 줘.

[요청] 'result.txt'를 이용해 분석 보고서를 작성해 줘. 임원 보고용이므로 전문 용어보다 주요 결과를 요약하고, 비즈니스에 참고할 인사이트와 비즈니스에 반영할 사항을 제안해 줘.

[작성 규칙]
- 개조식, 단문으로 작성하고 과장된 표현이나 비유는 쓰지 말 것
- 전문 보고서 양식을 갖추되, 임원이 읽는 문서이므로 분량이 과하지 않게 할 것
- 도표나 그래프로 표현하는 편이 나은 내용은 도표나 그래프로 넣고, 이해를 돕는 설명을 함께 달 것

[산출물] 아래 2종을 각각 docx와 pdf로 출력해 줘.
1. 요약본: 핵심만 담아 임원이 바로 읽을 수 있는 보고서 (짧더라도 보고서 형식은 유지)
2. 상세본: 문서로 보관할 보고서 (출처 등을 모두 포함)
