첨부한 'P3_driver_attrition.csv'(배송기사 30,000명, 17개 열)와 변수 설명 파일, 10개 행 샘플을 보고 아래 분석을 모두 수행하는 python 코드를 작성해줘.

[상황]
배송기사의 6개월 내 이탈률이 높다. 인사팀은 소득을 올리면 해결된다고 보지만, 현장에서는 근무시간, 휴무일 수, 야간 근무 비중, 경로 난이도, 관리자 면담이 더 중요하다고 본다. 제한된 예산으로 어떤 기사에게 어떤 리텐션 정책을 먼저 적용할지 정해야 한다.

[0. 공통 전처리 및 기술통계]
[1. 독립표본 t-test, 카이제곱 검정] 이탈자와 재직자의 특성 차이 비교
[2. 이진 분류 (로지스틱 회귀, 의사결정나무, XGBoost)] 이탈 예측 성능 비교
[3. 변수 중요도 (Permutation Importance, SHAP)] 이탈 핵심 요인 도출
[4. What-if 시뮬레이션] 휴무 1일 확대, 근무시간 1시간 단축, 면담 2회 추가 시 예측 이탈률 변화
[5. 이탈 위험 점수화 및 정책 우선순위] 위험 상위 10% 기사에 대한 맞춤형 정책과 예상 비용 대비 효과

출력: 분석 방법, 결과표, 핵심 수치, 간단한 해석을 'result.txt'에 저장하고, 그래프는 png로 figures 폴더에 저장할 것. 하나의 .py를 실행하면 모두 생성되게 할 것.
보고서 생성 프롬프트Claude
첨부한 'result.txt'와 그래프를 이용해 배송기사 이탈 분석 보고서를 작성해줘.
같은 분석을 읽는 사람에 맞춰 두 종류로 만들어줘.

1. 경영진 보고용 요약본(4쪽): 결정에 필요한 결론, 핵심 요인, 정책별 효과 비교, 제안만 담을 것
2. 팀 내부용 상세본(16쪽): 분석 방법, 검정과 모델 결과, 변수 중요도, What-if 시뮬레이션, 위험 상위 10% 정책안과 비용까지 담을 것

그래프는 13장 중 결론에 필요한 것만 골라 넣고, 그림마다 한 줄 해석을 달아줘.
수치는 result.txt에 있는 값만 쓰고, 상관관계를 인과관계처럼 쓰지 마. docx와 pdf로 만들어줘.

작업 과정

  1. 독자별로 보고서 2종 작성: 경영진용 4쪽 요약본, 팀 내부용 16쪽 상세본
  2. 분석 그림 13장 중 주요 5장 사용
